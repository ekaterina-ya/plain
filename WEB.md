# Plain Web

Форк [Plain](https://github.com/gregmos/plain) с веб-версией на своём сервере: та же библиотека заметок — в браузере на компьютере, iPhone и iPad. Десктопный Plain остаётся как есть и может работать с той же папкой.

*A fork of Plain with a self-hosted web version: the same library in a browser on a computer, iPhone and iPad. Docs below are in Russian.*

## Что умеет

- **Plain в браузере.** Чтение, rich, markdown, split, поиск, история версий, корзина, экспорт. Сервер — небольшой, на Rust (`server/`), берёт файловый код самого Plain (`src-tauri/src/fs.rs`, `tree.rs`, `search.rs`, `history.rs`), поэтому файлы сохраняются так же: байт в байт, атомарно, с историей.
- **Вход.** Пароль и код из приложения-аутентификатора (TOTP). Сессии на 30 дней, список устройств, выход везде. Ограничение попыток, `noindex` для поисковиков.
- **Телефон и планшет.** Своя раскладка, панель файлов выезжает сбоку, форматирование над клавиатурой, приложение на домашнем экране. Меню файла — долгое нажатие или свайп влево по строке.
- **Несколько устройств сразу.** Изменения приходят сразу. Без связи правка сохраняется на устройстве и уходит, когда сеть вернётся. Правили одну заметку в двух местах — Plain спросит, какую версию оставить.
- **«Поделиться».** Системное меню iPhone и iPad: markdown, html, текст, pdf (через печать) или текст сообщения — в Telegram, почту, AirDrop, «Файлы». Где меню нет — скачивание.
- **Импорт и скачивание.** Файлы с устройства (в том числе из «Файлов» и iCloud Drive) — в библиотеку; заметка — на устройство.
- **Вместе с десктопом.** Папка на сервере и папка на Mac — одна через Syncthing; правка в любом месте видна в обоих Plain за секунды.

Чего нет в вебе: команд, которые имеют смысл только на компьютере (показать в Finder, поверх окон, закрыть окно).

## Поставить

Нужны VPS с Linux x64 (проверено на Ubuntu 24.04), домен и обратный прокси с HTTPS (Caddy). Пошагово — [deploy/README.md](deploy/README.md): готовый релиз с GitHub, служба systemd, вход, Caddy, обновление и откат одной командой, синхронизация с Mac.

Релизы — метки `web-*` (сборка `.github/workflows/web-release.yml`). Метки `web-*-dr` — личная сборка автора форка, ставить её не нужно.

## Запустить у себя для разработки

```bash
npm install
cargo run --manifest-path server/Cargo.toml -- init --data data-dev/data   # пароль и QR
cargo run --manifest-path server/Cargo.toml -- --library data-dev/lib --data data-dev/data
npm run dev:web   # http://localhost:1420
```

Посмотреть без входа (только отладочная сборка и только `127.0.0.1`): `--dev-open`. Собранная версия: `npm run build:web` и сервер с `--static dist-web`.

Тесты: `npm test`, `cargo test` в `src-tauri/` и `server/`. Десктоп собирается как в оригинале.

## Как устроено

- `vite --mode web` подменяет `@tauri-apps/*` на `src/web/*`: вызовы команд идут на сервер (`POST /api/invoke/…`), изменения приходят по WebSocket (`/api/events`), черновики без связи — в IndexedDB.
- Сервер видит две папки — библиотеку и свои данные — и не выпускает пути за их пределы; секреты (вход, сессии) странице не отдаются.
- Правки в коде оригинала — минимальные: форк держится близко к нему, обновления вливаются.
